# Math Worksheet Review Portal

This repository hosts a static, interactive, and responsive student worksheet review portal powered by KaTeX and glassmorphic UI design.

## Features
- **Metric Dashboard**: Real-time summary of student reviewed problems, revision count, and concept mastery.
- **Problem Sidebar**: Quick navigation to individual reviewed items, badged by correctness status.
- **Grading & Step-by-Step Feedback**: Multi-line correction cards for student errors, detailing:
  - Error Analysis (what was wrong)
  - Step-by-Step Correct Solution (using KaTeX equations)
  - Conclusion (final answer option)
- **High-Fidelity Crops**: Inline visual images of the student's original written work steps next to the correction feedback.
